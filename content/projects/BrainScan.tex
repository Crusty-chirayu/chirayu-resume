\begin{cvproject}{\href{https://grvchnx.github.io/brainscan/}{\uline{BrainScan}} | TensorFlow.js, JavaScript, WebGL, IndexedDB, Grad-CAM}{}
    \item Built a client-side brain tumor classifier using TensorFlow.js, achieving 94.6\% validation accuracy across 4 MRI categories (glioma, meningioma, pituitary, and no tumor).
    \item Integrated real-time Grad-CAM heatmaps and an interactive comparison slider to visually inspect convolutional layer activations directly in the browser.
    \item Optimized inference to $<$80ms per scan using WebGL shaders and cut repeat load times by 68\% via IndexedDB weight caching with zero server-side data transfer.
\end{cvproject}
