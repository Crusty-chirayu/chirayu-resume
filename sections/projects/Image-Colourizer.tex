\begin{cvproject}{\href{https://github.com/grvsnh/Image-Colorization}{\uline{Image Colorization with Deep Learning}} | Python, TensorFlow, OpenCV, Streamlit, CNNs}{}
    \item Built a dual-model image colorization pipeline combining a custom CNN trained on 10,000+ images (Oxford-IIIT Pet dataset) with a pretrained ECCV 2016 model for grayscale-to-RGB chromatic reconstruction.
    \item Implemented an end-to-end LAB color space pipeline that extracts luminance (L) to predict chrominance (AB) channels, achieving sub-120ms inference latency per 512$\times$512 image.
